# Xray configuration

The runtime configuration is generated by `server.js` at startup.

Railway terminates public TLS, so the Xray inbound intentionally uses:
- VLESS
- WebSocket
- security: none (inside the container)
- path: /api/ws

The public client configuration uses:
- TLS: enabled
- port: 443
- SNI/Host: Railway public domain

Do not expose XRAY_PORT publicly.
